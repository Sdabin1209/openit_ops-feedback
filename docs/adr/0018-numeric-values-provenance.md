# 0018. 숫자 값의 출처 분류 (측정·표준·제약·임의)

- 상태: 기록(헤드 결정, 표준성 점검 2026-10-29 "전 영역: 근거 없는 임의 값"). **값은 바꾸지 않았다.** 이 ADR은 각 값이 어디서 왔는지를 분류하고, 측정하지 않았음을 적는다.
- 분류 뜻: **측정** = 이 영역에서 측정해 얻은 값. **표준** = 이름 있는 표준·문서가 정한 값. **제약** = 계약·이웃 영역·사용자 결정 등 이 영역 밖이 정한 값. **임의** = 위 셋에서 나오지 않았고 보수적으로 잡은 값. 이 영역에서 "측정"으로 분류할 수 있는 값은 아래 한 줄을 빼고 **없다**(처리량·지연·오탐을 측정한 적이 없다).
- 측정에 가까운 유일한 기록: ADR 0008 결과의 `/readyz` 2.0초, 수집 최악 7.0초는 상한이 걸렸는지 본 **관찰**이며 정상 지연의 측정이 아니다.

| 값 | 위치 | 분류 | 출처·메모 |
| --- | --- | --- | --- |
| DB 접속 3초, 문장 3초 | `pgbase.py` DEFAULTS | 제약 + 추정 | survey-service가 같은 문제에 쓴 값과 맞춤(그 영역 문서가 정본, 이 영역은 직접 확인 안 함) + 문장이 단건 INSERT/SELECT라는 코드 읽기. 정상 지연 측정 안 함(ADR 0008) |

- 왜 값을 바꾸지 않았나: 임의 값을 다른 임의 값으로 바꾸면 근거가 생기지 않는다. 측정하기 전까지는 설정으로 바꿀 수 있는 것(환경 변수, 설정 파일)은 이미 그렇게 되어 있다. 코드 상수인 것은 측정 계획이 생기면 설정으로 올린다.
- 측정 계획: **없다**(이 영역은 운영 trace도 부하도 갖고 있지 않다). 운영 지연·처리량이 측정되면 이 표의 "임의" 행부터 다시 정한다.
- 되돌리는 조건: 값이 측정되거나 표준·계약에서 정해지면 이 표의 해당 행을 갱신하고, 값이 바뀌면 그 값의 ADR을 새 ADR이 대체한다.
