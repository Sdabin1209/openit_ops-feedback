# 0010. 수집 서버는 표준 라이브러리 HTTP 서버

- 상태: 채택(근거 기록은 일부만 있음).
- 맥락: ingest-api는 라우트가 5개이고 JSON만 다룬다.
- 결정: `http.server.ThreadingHTTPServer`를 감싼 `BoundedServer`(동시 연결 상한, 소켓 timeout)를 쓴다. 의존 라이브러리를 늘리지 않는다.
- 왜: 선택 당시의 비교 기록은 **근거 기록 없음**(git log ee0715d에 설명 없음). 현재 판단: 라우트가 적고 의존·이미지 크기를 최소로 두는 것이 이점이며(`requirements.lock`이 짧다), 처리량은 측정 안 함. 한계는 점검 A9/B10이 지적했고 연결 상한·timeout·SIGTERM 처리로 보완했다.
- 대안: FastAPI 등 프레임워크 -> 의존·이미지가 커진다. 처리량 요구가 정해지면 재검토.
- 결과: 얻는 것은 의존 최소. 감수하는 것은 속도 제한·HTTP/2·비동기 없음, 연결당 스레드.
- 되돌리는 조건: 처리량이 측정되어 부족하거나 속도 제한 같은 기능이 필요해지면 프레임워크로.
